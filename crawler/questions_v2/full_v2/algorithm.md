## 1. 最小覆盖子串（LeetCode 76, Hard）如何用滑动窗口实现？

> 原题 ID：`q0005`

**高频程度**：★★★★★

**考察点**：考察滑动窗口在「求最小满足条件的子串」类问题上的标准套路与边界处理。

**回答框架**：

1) 用 need 记录 t 的字符需求，window 记录窗口内字符数，valid 记录已满足的字符种类数；2) right 扩张并更新 window，当 valid==need.size 时进入收缩；3) 收缩 left 并更新最小长度与起点，直到窗口不再满足；4) 返回最小窗口子串，无解返回空串。

**参考回答**：

双指针滑动窗口：用哈希表记录 t 中各字符需求频次；right 扩张窗口，当窗口满足所有需求时尝试收缩 left；维护最小长度。时间 O(n)，空间 O(字符集)。

初始化 need 计数 t 各字符；窗口 [left, right]；right 移动并减 need 计数；当窗口 valid（满足所有需求）时记录并更新最小长度，然后 left++ 直到不再满足；重复至末尾。

## 9. 手撕代码：实现反转链表？

> 原题 ID：`q0085`

**高频程度**：★★★★★

**考察点**：考察反转链表的三指针迭代写法与边界处理。

**回答框架**：

1) 初始化 prev=None、cur=head；2) 每轮先存 nxt=cur.next，再令 cur.next=prev，然后 prev/cur 后移；3) cur 为空时 prev 即新头；4) O(n) 时间 O(1) 空间；注意空链与单节点边界。

**参考回答**：

迭代三指针是标准答案：初始化 prev = None，cur = head，然后循环 while cur 不为空：先把 nxt = cur.next 暂存（否则改指针后会断链），再把 cur.next 指向 prev，接着 prev = cur、cur = nxt。循环结束时 cur 为空，prev 就是新的头节点，返回 prev。时间是 O(n)，每个节点只访问一次；空间是 O(1)，只用了三个指针。

边界要处理两种：空链表直接返回 None；单节点链表循环一次后 prev 就是它自己，天然正确。

递归写法是 reverse(head.next) 之后让 head.next.next = head、head.next = None，返回递归结果。时间同样 O(n)，但空间是 O(n) 的递归栈，链表很长时会栈溢出，所以面试一般优先写迭代。

延伸考点：这段「三指针」逻辑是 k 个一组反转、反转区间 [m,n]、回文链表判断的基础，讲的时候可以主动提一句，显得有体系。

**常见追问**：递归版反转链表的时间空间复杂度是多少？有什么风险？

## 12. 如何用动态规划计算不同二叉搜索树的数量？

> 原题 ID：`q3264`

**高频程度**：★★★

**考察点**：考察卡特兰数型 DP：以每个节点为根、左右子树方案数相乘再求和。

**回答框架**：

1) BST 中序递增，选定根 t 后左子树必由 {1..t-1} 组成、右子树由 {t+1..n} 组成，互不交叉；2) 乘法原理：以 t 为根的方案数 = f(t-1)×f(n-t)；3) 对所有 t 求和得 f(n)=Σ f(t-1)f(n-t)；4) 边界 f(0)=1（不能为 0）、f(1)=1；也可用卡特兰数闭式。

**参考回答**：

以每个数 t 为根，左子树取所有小于 t 的数构成的任意 BST，右子树取所有大于 t 的数构成的任意 BST，左右方案数相乘即得以 t 为根的方案数，再对所有 t 求和即得全部 BST 数量。

这是「不同的二叉搜索树」问题的核心思想，本质是组合数学中的乘法原理 + 递归分治。

1) 问题定义：给定 n 个互不相同的节点值 1..n，问能构造出多少棵结构不同的二叉搜索树（BST）。

2) 关键观察（BST 的性质）：BST 的中序遍历是递增序列。因此一旦选定根节点 t，左子树必然由 {1..t-1} 组成，右子树必然由 {t+1..n} 组成，节点集合被根完全划分，不存在交叉。

3) 乘法原理：设 f(k) 表示 k 个节点能构成的 BST 数量。以 t 为根时，左子树有 t-1 个节点，方案数为 f(t-1)；右子树有 n-t 个节点，方案数为 f(n-t)。左右子树的选择互相独立，所以以 t 为根的方案数是 f(t-1) * f(n-t)。

4) 枚举所有根：t 可以取 1..n 中任意一个，这些情况互斥且完备，所以 f(n) = Σ_{t=1..n} f(t-1) * f(n-t)。

5) 边界：f(0)=1（空树算一种方案，这是乘法原理的「单位元」，不能设为 0，否则所有结果都为 0）；f(1)=1。

6) 通俗类比：把根 t 想成「队长」，左边队伍和右边队伍各自排队方式独立，总排队方式 = 左边方式数 × 右边方式数；换一个队长就换一种分队方式，把所有队长的结果加起来就是总方案数。

7) 该递推式正是卡特兰数 C_n = (1/(n+1)) * C(2n, n)，f(n) 即第 n 个卡特兰数。

8) 适用场景：计数类 DP（区间 DP）、树的形态计数、括号匹配、出栈序列计数等，凡是「选一个分割点，左右独立组合」的结构都可用此思路。

**常见追问**：为什么 f(0) 必须定义为 1？

## 13. 快速排序的核心思想与实现要点？

> 原题 ID：`q4139`

**高频程度**：★★★★

**考察点**：考察快速排序的分治思想、partition 与退化防范。

**回答框架**：

1) 选 pivot 做 partition，小于放左、大于放右，递归两侧；2) 平均 O(n log n)，最坏 O(n²)（已排序且取端点为 pivot）；3) 优化：随机 pivot、三数取中、三路划分处理大量重复；4) 原地排序、不稳定，注意递归深度与栈溢出。

**参考回答**：

分治：选基准 pivot，partition 把小于放左、大于放右，递归左右。平均 O(n log n)，最坏 O(n^2)（已有序且选端为 pivot，用随机或三数取中缓解）。原地、不稳定。注意边界与 pivot 选择防栈溢出。

代码骨架（三路划分版，能同时抗重复元素）：
def qsort(a, lo, hi):
    if lo >= hi: return
    pivot = a[random.randint(lo, hi)]     # 随机选基准
    lt, i, gt = lo, lo, hi
    while i <= gt:
        if a[i] < pivot: a[lt], a[i] = a[i], a[lt]; lt += 1; i += 1
        elif a[i] > pivot: a[i], a[gt] = a[gt], a[i]; gt -= 1
        else: i += 1
    qsort(a, lo, lt - 1); qsort(a, gt + 1, hi)

复杂度：平均 O(n log n)（每层扫描 O(n)，期望递归深度 O(log n)），最坏 O(n²)（每轮划分极度不平衡）。退化场景是「已排序数组 + 固定取端点做 pivot」和「大量重复元素 + 二路划分」。优化手段：随机化 pivot、三数取中、三路划分、内省排序（递归过深转堆排序）。快排原地、不稳定，且递归深度过大会栈溢出，可改成小数组用插入排序的混合实现。

**常见追问**：为什么快排是「不稳定」排序？举个会打乱相等元素的例子。

**考察点**：考察异或的抵消性质，以及其在数组去重、找缺失数等算法题中的应用。

**回答框架**：

异或（XOR）是按位运算：两位相同得0，不同得1；它有三个关键性质：1) 自反性 a^a=0，a^0=a；2) 交换律和结合律，所以一堆数异或的顺序可以任意调整；3) 异或相当于「不进位的二进制加法」；经典题一：数组中只有一个数出现一次，其余都出现两次，求这个数；把所有元素异或起来，成对的数因为 a^a=0 互相抵消，最后剩下的就是答案

**参考回答**：

异或（XOR）按位比较：相同为 0、不同为 1。它满足 `a ^ a = 0`、`a ^ 0 = a`，并满足交换律和结合律，因此一组元素可以任意重排后让成对元素抵消。

典型应用一：数组中只有一个数出现一次、其余出现两次时，把全部元素异或，结果就是落单数。应用二：有两个数各出现一次时，先得到它们的异或，再取其中任意一个为 1 的位把数组分组，两组分别异或即可。应用三：把 `0..n` 与数组元素一起异或，可找出缺失数。上述方法都可做到 O(n) 时间、O(1) 额外空间。

异或也常用于状态翻转、校验和某些密码学构造，但“把数据和固定密钥做一次异或”本身不是安全加密方案；算法题里应优先说明它的抵消性质和适用前提。
